# CNN Architecture · CS172 Computer Vision I

37 slides for a 90-minute undergraduate lecture by Jiayuan Gu, ShanghaiTech University. Follows the existing CNN fundamentals deck. Open **index.html** directly in a desktop browser: all fonts, math, diagrams, scripts, and interactions are local. No server or installation is needed to present. Reading links need internet when clicked.

The lecture covers layer contracts and cost, VGG, global pooling, Inception, residual networks, depthwise separable convolution, transfer, and fair evaluation. It includes direct calculation and diagnosis questions, an interactive width/resolution explorer, and a three-question reversible exit check. Question prompts have no time limits or group instructions. Eight comparison tables have become editable illustrations; the tensor/context audit is retained as a table. The objectives slide is removed. Teaching details and homework are in **TEACHING_PLAN.md**. Calculation/code builds use one or two grouped reveals; bullet-only exposition stays static.

## Edit and refresh

**index.html** is the only editable slide-content source. Edit readable sections with stable IDs and their inline `slide-meta` notes/reference records. Math is editable LaTeX inside `<m>` elements. Styles, navigation, and interactions are in **source/**. Five teaching diagrams are reproducible SVG assets generated by **tools/draw_figures.py**. The new illustrations are readable inline SVG in **index.html**, styled in **source/style.css**, so their labels and geometry have the same canonical content source as the slides. Six high-resolution crops reuse original paper and reference-lecture artwork; **tools/extract_figures.py** reproduces these from the four PDFs retained in **source/references/**. The provenance JSON records URLs, page numbers, crop bounds, and hashes. `SPEAKER_NOTES.md` and `SOURCE_MAP.csv` are derived; regenerate them after changing order, titles, notes, or citations. `SOURCES.md` records provenance and adaptations. `QA_REPORT.md` records verification and limits.

Authoring requires Python 3.9+, packages in `tools/requirements.txt` (complete verified dependency pins are in `tools/requirements-lock.txt`), and Chrome or Playwright Chromium. The presentation does not require authoring tools. One-time setup in a reusable environment outside the checkout:

```sh
python3 -m venv /private/tmp/cnn-architecture-venv
/private/tmp/cnn-architecture-venv/bin/pip install -r lectures/CNN_Architecture/tools/requirements.txt
```

From the repository root, later refresh and export with:

```sh
/private/tmp/cnn-architecture-venv/bin/python lectures/CNN_Architecture/tools/refresh.py
/private/tmp/cnn-architecture-venv/bin/python lectures/CNN_Architecture/tools/verify_math.py
/private/tmp/cnn-architecture-venv/bin/python lectures/CNN_Architecture/tools/export_pdf.py --check --screenshots /private/tmp/cnn-architecture-slides
/private/tmp/cnn-architecture-venv/bin/python lectures/CNN_Architecture/tools/review_pdf.py --output /private/tmp/cnn-architecture-pdf-review
```

If changing source-figure crops, edit the crop records in `tools/extract_figures.py` and run it before refresh. It preserves the original artwork and labels at high resolution; it does not redraw the figures. The lecture block crop masks a neighboring blue annotation without changing its block. Sources retain their original rights.

Set `CHROME` to a Chromium executable if necessary; macOS tools default to installed Google Chrome. The exporter checks the actual offline `file://` path and restores defaults before printing. It retains text and links in **CNN_Architecture.pdf**, 1080×607.5 pt. Review every page after slide changes. Screenshot/contact-sheet outputs stay outside this folder.

Optional execution of the residual block (stable ID `27-code`):


No dataset or weights are downloaded by the model check. It verifies shapes, parameter counts, gradients, and evaluation on synthetic inputs. Hosting, upload, and ZIP packaging are separate tasks.
