Harvard CS109A · pp. 7Margin geometry05 / 55

Normalize the score to get a distance

\text{signed distance to }\mathcal H=\frac{w^\top x+b}{\lVert w\rVert_2}

For labeled example i, the geometric margin is

\gamma_i=\frac{t_i(w^\top x_i+b)}{\lVert w\rVert_2}

Positive means correct; larger means farther from the boundary on the correct side.

The dataset margin is \gamma=\min_i\gamma_i.

(w,b)\quad\text{and}\quad(aw,ab),\quad a>0

They define the same boundary and predictions.

Functional margin

t_i(w^\top x_i+b)

Multiplies by a.

Geometric margin

\frac{t_i(w^\top x_i+b)}{\lVert w\rVert_2}

Stays unchanged.

An unnormalized score alone cannot identify the widest margin.

Harvard CS109A · pp. 7,8,9,10,11Margin geometry11 / 55

Maximum margin becomes a convex problem

\min_{w,b}\ \frac12\lVert w\rVert_2^2\text{subject to }\quad t_i(w^\top x_i+b)\ge1\quad\text{for all }i

Minimizing the squared norm maximizes the canonical geometric margin.

A convex quadratic objective with affine constraints: every local optimum is global.

Hard margin requires linearly separable data.

The dual problem

Replace a weight vector with one coefficient per training example.

Stanford CS229 · §6.5–6.6The dual problem13 / 55

Put the constraints into a Lagrangian

Write each constraint as 1-t_i(w^\top x_i+b)\le0.

\mathcal L(w,b,\alpha)=\frac12\lVert w\rVert^2+\sum_i\alpha_i[1-t_i(w^\top x_i+b)]\alpha_i\ge0

Each multiplier prices the corresponding training constraint.

Stanford CS229 · §6.5–6.6The dual problem14 / 55

Eliminate the primal variables

\nabla_w\mathcal L=w-\sum_i\alpha_it_ix_i=0
\boxed{w=\sum_i\alpha_it_ix_i}
\frac{\partial\mathcal L}{\partial b}=-\sum_i\alpha_it_i=0\quad\Longrightarrow\quad\sum_i\alpha_it_i=0

The equality constraint comes from the unregularized bias.

Stanford CS229 · §6.5–6.6The dual problem15 / 55

Substitute the weighted sum back in

Eliminate b using \sum_i\alpha_it_i=0:

\mathcal L=\frac12\lVert w\rVert^2+\sum_i\alpha_i-w^\top\sum_i\alpha_it_ix_i
=\sum_i\alpha_i-\frac12\left\lVert\sum_i\alpha_it_ix_i\right\rVert^2
=\sum_i\alpha_i-\frac12\sum_{i,j}\alpha_i\alpha_jt_it_j\,x_i^\top x_j
Stanford CS229 · §6.5–6.6The dual problem16 / 55

Maximize a concave quadratic in α

\max_\alpha D(\alpha)=\sum_i\alpha_i-\frac12\sum_{i,j}\alpha_i\alpha_jt_it_j\,x_i^\top x_j\alpha_i\ge0,\qquad\sum_i\alpha_it_i=0

The data enter through inner products, not individual coordinates.

For separable data, strong duality gives the same optimum as the hard-margin primal.

x_+=(1,0), t_+=+1.

Stanford CS229 · §6.5–6.6The dual problem20 / 55

Optimize two coefficients at a time

\sum_i\alpha_it_i=0

Changing one coefficient usually breaks the equality.

Move a pair along a feasible direction:

\alpha_i\leftarrow\alpha_i+t_i\delta,\qquad\alpha_j\leftarrow\alpha_j-t_j\delta
\delta^*=\operatorname{clip}_{[l,u]}\!\left(\frac{d^\top\nabla D(\alpha)}{d^\top Qd}\right)

d is the pair direction; Q_{ij}=t_it_jx_i^\top x_j. For positive curvature, clip to the feasible interval [l,u].

Our tiny demos use exhaustive pair-coordinate ascent, not a production SMO implementation.

Harvard CS109A · pp. 34Kernels36 / 55

A valid kernel behaves like an inner product

For every finite input set, the Gram matrix G_{ij}=k(x_i,x_j) must be symmetric and positive semidefinite.

v^\top Gv\ge0\qquad\text{for every real vector }v
Lineark(x,z)=x^\top z
Polynomialk(x,z)=(x^\top z+c)^d, c\ge0, positive integer d
RBFk(x,z)=e^{-\gamma\lVert x-z\rVert^2}, \gamma>0

Fit scaling on training data; select kernel settings and C on validation data.

A violated margin tells scores how to move

Let V_i=\{j\ne y_i:s_{ij}-s_{i,y_i}+1>0\}.

\frac{\partial L_i}{\partial s_{ij}}=1\ (j\in V_i),\qquad\frac{\partial L_i}{\partial s_{i,y_i}}=-|V_i|

Other competing scores have derivative zero.

Default cat example: only car violates.

\nabla_sL_i=(-1,1,0)^\top

A descent step raises the true score and lowers the violating score.

At a hinge kink, choose a valid subgradient; zero is a common convention.

CS231n notesLoss and optimization48 / 55

Convert score gradients into weight gradients

For one example, set d_i=\nabla_{s_i}L_i.

\nabla_WL_i=d_ix_i^\top,\qquad\nabla_bL_i=d_i
g_W=\frac1B\sum_{i\in\mathcal B}d_ix_i^\top+\lambda W,\qquad g_b=\frac1B\sum_{i\in\mathcal B}d_i
W\leftarrow W-\eta g_W,\qquad b\leftarrow b-\eta g_b

Learning rate \eta>0; B is the actual minibatch size.

A minibatch subgradient method scales training

# Batch rows; use the current weights to form all gradients.
for Xb, yb in shuffled_minibatches(X, y):
    scores = Xb @ W.T + b
    d = multiclass_hinge_score_grad(scores, yb)
    W -= eta * (d.T @ Xb / len(Xb) + lam * W)
    b -= eta * d.mean(axis=0)

Repeat: sample → score → measure violations → update.
