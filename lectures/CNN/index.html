Write the operator precisely

Z_{n,o,i,j}=b_o+\sum_{c=0}^{C_{\mathrm{in}}-1}\sum_{u=0}^{K-1}\sum_{v=0}^{K-1}\Theta_{o,c,u,v}\,\widetilde X_{n,c,iS+u,jS+v}

n: image · o: output channel

i,j: output row and column

c: input channel · u,v: kernel offsets

\widetilde X: input after zero padding

S: spatial stride · K: kernel side

One b_o is reused across the output map.

Deep-learning “convolution” usually computes cross-correlation: the kernel is not flipped.

D2L · §7.5Context and downsampling26 / 36

Equivariance is different from invariance

T_\delta shifts an image or feature map by \delta pixels.

Equivariance

f(T_\delta X)=T_\delta f(X)

Shift the input; the feature map shifts.

Stride-1 convolution on an infinite grid, or away from affected boundaries.

Invariance

f(T_\delta X)=f(X)

Shift the input; the output stays the same.

An additional property, not implied by sharing.

Max pool, K=2,S=2: [0,1,0,0]\mapsto[1,0]

Shift right one pixel: [0,0,1,0]\mapsto[0,1].

import torch
from torch import nn

model = nn.Sequential(
    nn.Conv2d(3, 8, 3, padding=1), nn.ReLU(),
    nn.MaxPool2d(2),
    nn.Conv2d(8, 16, 3, padding=1), nn.ReLU(),
    nn.MaxPool2d(2),
    nn.AdaptiveAvgPool2d(1), nn.Flatten(1),
    nn.Linear(16, 10),

x = torch.randn(4, 3, 32, 32)
assert model(x).shape == (4, 10)

Repair two common tensor mismatches

Channels in the wrong axis

images.shape  # (4, 32, 32, 3)
nn.Conv2d(3, 8, 3)(images)

Conv2d expects channels in axis 1.

Move the last axis to axis 1:

images.permute(0, 3, 1, 2)
# (4, 3, 32, 32)

Too many features for the head

features.shape  # (4, 16, 8, 8)
features.flatten(1)
# (4, 1024)

A 16-feature head cannot take 1,024 values.

Average each map before flattening:

nn.AdaptiveAvgPool2d(1)
# (4, 16, 1, 1) → (4, 16)

Architectural assumptions have limits

  • Position: global averaging discards spatial arrangement.
  • Detail: downsampling can remove small objects and thin structures.
  • Variation: sharing alone does not handle rotation, scale, or changed imaging conditions.
  • Influence: pixels inside a receptive field need not affect the output equally.

Connect structure, geometry, and learning

  1. Structure: local connections and shared filters encode reusable evidence.
  2. Computation: each response sums spatial and channel products.
  3. Geometry: kernel, stride, and padding determine output shape.
  4. Context: depth and downsampling expand receptive fields.
  5. Learning: shared gradients and familiar losses train the whole classifier.

Check your understanding

  1. Input 8\times32\times32; 16 filters, K=3,S=2,P=1.
    Output shape and parameter count?

    16\times16\times16; 16(8\cdot9+1)=1{,}168 parameters.

  2. Two 3\times3, stride-1 convolutions: receptive field?

    5\times5 in the original input, for an output away from the border.

  3. Does weight sharing imply translation invariance?

    No. A shift can move the feature map; strided pooling can change which window captures a feature.
