The nearest-neighbor rule

The diamond marks the unlabeled query \mathbf q.

Training

Store N labeled examples:

\{(\mathbf x^{(i)},y^{(i)})\}_{i=1}^{N}

Prediction

For a query \mathbf q, find its closest stored example.

i^\star=\arg\min_{1\leq i\leq N}d(\mathbf q,\mathbf x^{(i)})\hat y(\mathbf q)=y^{(i^\star)}

Nearest neighbor in NumPy

# X_train: (N, D), q: (D,), y_train: (N,)
# Rows index examples; columns index coordinates.
X = X_train.astype(np.float32)
q = q.astype(np.float32)

distances = np.abs(X - q).sum(axis=1)
i_star = np.argmin(distances)
y_pred = y_train[i_star]

Row i stores \mathbf x^{(i)}; the code returns \hat y(\mathbf q).

Cast before subtraction to avoid uint8 wraparound. NumPy uses zero-based indices.

CS231n · nearest neighborNearest neighbors16 / 54

Voting among nearby examples

\mathcal I_k(\mathbf q) contains the indices of the k nearest stored examples.

\hat y(\mathbf q)=\operatorname{mode}\{y^{(i)}:i\in\mathcal I_k(\mathbf q)\}

Choose the most frequent label among these k examples.

Larger neighborhoods can reduce sensitivity to individual examples.

For a vote tie, use the tied class whose nearest neighbor is closest.

CS231n · Lecture 2Model selection25 / 54

Two tempting evaluation mistakes

Choose k using training accuracy?

With distinct stored inputs, 1-NN can classify each training example using itself.

This does not measure performance on unseen images.

Choose k using test accuracy?

The test set then influences the model choice.

Its score no longer provides an independent final evaluation.

CS231n · Lecture 2Model selection27 / 54

Cross-validation reuses limited data

For each candidate hyperparameter setting:

  1. Fit on four folds.
  2. Validate on the remaining fold.
  3. Rotate the held-out fold and average.

After selection, fit on all development data and evaluate on the untouched test set.

CS231n · Lecture 2Linear classification39 / 54

Multiclass decision regions

\hat y=\arg\max_c s_c(x)

Example: s_1=x_1,\quad s_2=x_2,\quad s_3=0.

Class c wins where its score is at least every competing score.

(w_c-w_j)^T x+(b_c-b_j)\geq0\quad\forall j

Each pairwise boundary is linear. A class region can have several boundary pieces.

MIT Vision Book · §9.7.3Probabilistic classification47 / 54

Maximize the likelihood of training labels

Training labels: y_1,\ldots,y_N; parameters: \theta=(W,b).

\max_\theta\prod_i p_\theta(y_i\mid x_i)
\Longleftrightarrow\quad\max_\theta\sum_i\log p_\theta(y_i\mid x_i)
\Longleftrightarrow\quad\min_\theta\frac1N\sum_i\underbrace{-\log p_\theta(y_i\mid x_i)}_{\text{per-example loss}}

Assume labels are conditionally independent given inputs and parameters.

Checking the behavior of softmax loss

If all C scores are equal?

For ten classes: \ell\approx2.3026.

CS231n · Lecture 2From probabilities to loss50 / 54

A numerically stable implementation

\ell_i=\log\sum_j e^{s_j-m}+m-s_{y_i},\qquad m=\max_j s_j
# S: (N, C); y: integer class indices, shape (N,)
z = S - S.max(axis=1, keepdims=True)
log_Z = np.log(np.exp(z).sum(axis=1))
loss = (log_Z - z[np.arange(len(y)), y]).mean()

Subtracting a common constant leaves softmax probabilities unchanged.

Prefer the framework’s fused cross-entropy function in training code.
