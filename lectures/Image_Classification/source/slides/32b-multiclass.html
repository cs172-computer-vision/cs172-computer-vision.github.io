Multiclass decision regions

\hat y=\arg\max_c s_c(x)

Example: s_1=x_1,\quad s_2=x_2,\quad s_3=0.

Class c wins where its score is at least every competing score.

(w_c-w_j)^T x+(b_c-b_j)\geq0\quad\forall j

Each pairwise boundary is linear. A class region can have several boundary pieces.
