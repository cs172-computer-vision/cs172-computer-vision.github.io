Checking the behavior of softmax loss

If all C scores are equal?

p_c=1/C,\qquad\ell=\log C

For ten classes: \ell\approx2.3026.

How small or large can the loss be?

p_y\to1\Rightarrow\ell\to0p_y\to0\Rightarrow\ell\to+\infty

No finite maximum.

For finite logits and C > 1, the loss is strictly positive. Zero is an infimum.
