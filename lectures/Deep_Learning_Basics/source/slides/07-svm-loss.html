Multiclass SVM loss

Add the hinge penalties for all incorrect classes.

L_i=\sum_{j\ne y_i}\max\bigl(0,s_j-s_{y_i}+1\bigr)L_{\mathrm{data}}=\frac{1}{N}\sum_{i=1}^{N}L_i
N: training examplesC: classess\in\mathbb{R}^{C}: scores

Exclude the true class from the sum. We average over examples, not over classes.
