L2 expresses a preference among equal fits

For x=(1,1,1,1)^\top:

w_a=(1,0,0,0)^\topw_b=(0.25,0.25,0.25,0.25)^\top

Both give w^\top x=1.

Which weight vector does L2 prefer?

\lVert w_a\rVert_2^2=1\qquad\lVert w_b\rVert_2^2=0.25

For this input, L2 prefers the distributed weights w_b.

Equal predictions on this input do not imply equal predictions on all inputs.
