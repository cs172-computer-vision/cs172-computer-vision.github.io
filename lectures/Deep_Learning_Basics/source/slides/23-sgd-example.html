One minibatch, one concrete SGD step

Two sampled examples give data gradients:

g^{(1)}=(2,-4)^\top,\qquad g^{(2)}=(0,-2)^\top

Start at \theta_t=(2,-1)^\top, use \eta=0.1, and set \lambda=0.

g_t=\tfrac12\bigl(g^{(1)}+g^{(2)}\bigr)=(1,-3)^\top
\theta_{t+1}=(2,-1)^\top-0.1(1,-3)^\top=(1.9,-0.7)^\top

Illustrative sample gradients. This update need not reduce the full training loss.
