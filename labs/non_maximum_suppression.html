Non-Maximum Suppression

Compare every pixel against the original gradient-magnitude image. Suppression changes only the output image; it must never change the values used for later comparisons.

Raw gradient magnitude \(M\)

Immutable input used for every local-maximum test.

NMS output

Begins as a copy of \(M\); non-maxima are progressively suppressed to zero.

For pixel \(p\), sample the raw magnitude image at \(p-\hat n\) and \(p+\hat n\), where \(\hat n\) is the gradient direction. Keep \(p\) only if it is no smaller than both neighbors.

Pixels are animated from highest to lowest \(M(p)\) only for presentation. The comparison itself always reads from the unchanged raw map, so processing order cannot affect the final NMS result.

Pseudo code

M_raw = gradient_magnitude.copy()
M_nms = M_raw.copy()
for p in pixels sorted by descending M_raw[p]:
    n  = unit_gradient_direction[p]
    m- = interpolate(M_raw, p - n)
    m+ = interpolate(M_raw, p + n)
    if M_raw[p] < m- or M_raw[p] < m+:
        M_nms[p] = 0
    else:
        M_nms[p] = M_raw[p]
