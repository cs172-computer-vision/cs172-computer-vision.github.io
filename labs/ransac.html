RANSAC / Line fitting

Fit a line when some observations do not belong. Sample two points, count nearby points, and keep the strongest consensus.

Try, predict, explain
  1. Increase the outlier fraction from 50% to 80%. How does N change at the same p?
  2. Switch to a manual threshold. What happens when τ is much smaller, or much larger, than σ?
  3. Show least squares on all points. Why does RANSAC usually resist outliers better?

1. Generate observations Inliers have Gaussian noise in x and y. Outliers are uniform. Changing these controls creates new data.

2. Set the inlier threshold Auto uses the known simulation σ. A point votes for a line when its perpendicular distance d ≤ τ. Changing a RANSAC setting resets the run and keeps the same observations.

3. Set the trial budget Two distinct points per trial; pairs can recur across trials.

What happens in one trial?

  1. Sample. Select two distinct observations uniformly and fit their line.
  2. Score. Measure every perpendicular distance; count points with d ≤ τ.
  3. Keep. Replace the best hypothesis if the consensus grows. Break ties using squared inlier residuals.
  4. Refit at the end. Fit a line to all points in the winning consensus using total least squares.

The generated inlier labels are never used to fit or score a line.
